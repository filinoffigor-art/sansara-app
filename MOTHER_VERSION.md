# SANSARA — материнская версия (0.22.0-mother)

Эта сборка — основа для всех следующих дополнений.

Правила:
1. Новые функции добавляются поверх; существующие экраны, роли, данные и логика не меняются без отдельной просьбы.
2. База Room: только аддитивные миграции (новые таблицы/колонки), версия БД растёт, данные пользователей сохраняются.
3. applicationId `ru.sansara.app` и ключ подписи не меняются, versionCode только растёт.
4. Каждая правка проходит сборку GitHub Actions и снимки экранов (workflow Screens).
5. Утверждённые экраны (приветствие, главный клиента, каталог, фильтр, список товаров, карточка товара, задание в цех) — эталон.
