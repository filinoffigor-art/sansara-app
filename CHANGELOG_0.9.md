# SANSARA 0.9.0 — Functional Visual Lock

Основа: последняя успешно собранная версия 0.8.1.

## Visual Lock
- Утверждённые reference-экраны сохранены как Source of Truth.
- Размеры, композиция, фирменный тёмно-золотой стиль и роли не менялись.
- Новая механика добавлена поверх существующих экранов через hotspots, overlays, scroll и отдельные функциональные экраны.

## Клиент
- Рабочая регистрация: поля, тип клиента, согласие, второй контакт (+ e-mail).
- Локальная заявка + готовый backend event для отдельного Telegram-бота регистрации.
- Вход по коду и сохранение клиентской сессии.
- Динамический клиент/статус/скидка.
- Поиск по SKU/названию, наличие/под заказ, категории и компактные фильтры.
- Каталог и популярные товары со scroll.
- Карточка товара, количество, добавление в корзину с возвратом назад.
- Корзина с количеством, удалением, скидкой и итогом.
- Оформление заказа: способ получения, адрес, комментарий.
- Экран «Заказ отправлен», история и статусы заказа.
- Приостановленный клиент может смотреть каталог, но не оформлять заказ.

## Администратор
- Динамические KPI и поиск по клиентам/заказам/товарам.
- Клиенты, карточка клиента, статусы, скидка, доступ к заказам, код входа.
- Обработка новых регистраций с генерацией клиентского кода.
- Управление заказами и последовательное изменение статусов.
- «Требует внимания»: регистрации, приостановленные, сборка, низкие остатки.
- Online controller.
- Новые тёмные настройки SANSARA: профиль, роли, клиенты, Tilda sync, порог остатков, уведомления, backup, export, about.
- Поддержка: +7 926 304-60-19.

## Производство / склад
- Дата устройства вместо статической даты.
- Убран поиск с production home, увеличен scroll-блок выпуска сегодня.
- Добавление позиции только из единого каталога.
- Категория → поиск → товар → сборщица → количество → приход.
- Черновик выпуска дня и массовое оприходование.
- История приходов с фотографиями.
- Physical / Reserved / Available с правилом Available = Physical - Reserved.
- Низкие остатки по настраиваемому порогу.
- CSV export в Downloads/SANSARA.

## Tilda / backend
- 120 тестовых товаров (20 × 6 категорий).
- Tilda YML sync: SKU, имя, категория, цена, качество, размер, фото, срок производства.
- Tilda не перезаписывает склад, резерв, клиентов, заказы и производство.
- Добавлен optional backend bridge для registration/order events. Telegram-токены в APK не хранятся.
